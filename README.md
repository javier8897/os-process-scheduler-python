Developed in Python as a final capstone project (chosen out of three options and adapted from Spanish to English) to integrate and apply all concepts learned throughout my university Algorithms & Data Structures course.

Built with clean Object-Oriented Programming, this CLI OS Process Scheduler features a Round-Robin queue (collections.deque), dynamic priority-aging to prevent starvation, recursive subtask call stacks, a custom Insertion Sort algorithm, and automated .txt file I/O for configurations and execution logs.
